
# 🎒 AI Packing List Generator

An AI-powered packing list application built with Python and Streamlit to help travelers prepare for their trips.

## ✨ Features

- 🧳 Generate packing lists for different trips and destinations
- 🌤️ Organize items based on trip details and activities
- 👕 Group items into useful packing categories
- ✅ Make trip preparation easier with an organized checklist
- 🎨 Interactive and user-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- JSON

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/chethansree77/ai-packing-list-generator.git
cd ai-packing-list-generator
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
pip install streamlit
```

If your project uses additional Python libraries, install those too.

### 5. Run the application

```bash
streamlit run app.py
```
